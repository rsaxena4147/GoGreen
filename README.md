# GoGreen 🌱

GoGreen is a web application focused on promoting eco-friendly habits and sustainable living. The platform encourages users to adopt greener practices and contribute toward a healthier environment.

## 🚀 Live Demo

🔗 https://gogreen-frontend.onrender.com/

---

# ✨ Features

- User-friendly and responsive interface
- Modern frontend design
- Fast and interactive experience
- Clean UI with smooth navigation
- Environment awareness platform
